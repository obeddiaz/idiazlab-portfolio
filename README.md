# iDiaz Lab — Portfolio

This is my personal developer portfolio built with Next.js and modern frontend tooling.

The goal of this project is to showcase my work, experiments and engineering approach in a clean and fast website.

🌐 Live site: [https://idiazlab.com](https://idiazlab.com)

---

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- next-themes (dark/light mode)
- Deployed on Vercel

---

## Features

- Responsive and accessible UI
- Dark / Light theme support
- Data-driven architecture (projects & experience)
- Smooth animations with Framer Motion
- Optimized for performance and SEO
